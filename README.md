# XYXM07.github.io

星月晓梦的个人站，使用 GitHub Pages 发布的静态网站。

包含个人主页与联系方式、小游戏、常用工具及心理测试。最新加入合成大西瓜、二维 CAD 编辑、分贝测试、进制转换、摩斯密码、JSON/YAML/CSV/TSV/XML 转换和 PDF 工具箱。

CAD 支持 DWG 导入、在线二维编辑和 DWG 2000（AC1015）保存，以及 DXF、SVG 与完整 JSON 工程。线段、圆、圆弧和直线多段线可编辑，文字、图块及其他实体只读保留；图层、图块定义和纸空间随文件保存。DWG 2000 使用索引色，自定义 RGB 颜色可能近似；标准三维视觉样式由 CAD 软件重建，其他无法完整写出的对象会阻止保存并提示。外部参照和专有代理对象可能无法完整显示。DWG 库 nasjidwg 0.18.0 使用 MIT 许可，模块在同源后台 worker 中按需加载，图纸不上传。

分贝工具默认显示数字电平 dBFS，使用参考读数校准后可显示估算声压级。PDF 支持合并、拆分、提取、旋转、预览、图片转 PDF 和文本提取，不提供 OCR。

文件在浏览器本地处理，麦克风仅在点击开启后请求权限。运行无需构建，上传根目录完整内容即可；使用相对资源路径与 hash 路由。依赖来源和许可证在 `vendor` 中。
