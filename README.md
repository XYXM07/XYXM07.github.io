# XYXM07.github.io

星月晓梦的个人站，使用 GitHub Pages 发布的静态网站。

包含个人主页与联系方式、小游戏、常用工具及心理测试。最新加入合成大西瓜、二维 CAD 编辑、分贝测试、进制转换、摩斯密码、JSON/YAML/CSV/TSV/XML 转换和 PDF 工具箱。

CAD 支持二维图形、ASCII DXF 与 JSON 工程，暂不支持 DWG 或三维图形。分贝工具默认显示数字电平 dBFS，使用参考读数校准后可显示估算声压级。PDF 支持合并、拆分、提取、旋转、预览、图片转 PDF 和文本提取，不提供 OCR。

文件在浏览器本地处理，麦克风仅在点击开启后请求权限。运行无需构建，上传根目录完整内容即可；使用相对资源路径与 hash 路由。依赖来源和许可证在 `vendor` 中。
