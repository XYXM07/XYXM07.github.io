# 星月晓梦的个人站

星愿刮刮乐（`#games/scratch`）：右侧选择四种票卡，仅保留宽幅刮刀升级。界面不显示中奖率；新购票卡的整票中奖率分别设为 60%、22%、10%、25%，购卡时生成对应的中奖或未中奖票面，兑奖完全按票面规则计算。新增免费刷盘子选项：拖动鼠标、手指或方向键擦掉圆形盘面污渍，擦净至少 98.5% 后自动清除残留边缘并获得 10 金币，每个盘子仅奖励一次，可重复免费领取。刷盘子与票卡进度分别保存，切换页面不丢进度，刷新或关闭页面后清空。晨光纸笺为三同图符，月庭来信为中奖号码与翻倍号码，星海邀约为 5×5 宾果卡与 24 个叫号刮区（自由格、横竖斜线、四角、X 形，全部叫号揭晓后兑一个最高奖级），极光秘卷为 8 个幸运图符与 6 条独立寻宝路线（图符可同时点亮多条路线，完成路线兑奖且奖金相加）。票面、奖金和概率在购入时确定，刮刀只影响刮开范围。使用原创 Canvas 图案及虚拟金币，支持手指、鼠标和空格操作；票面规则附有官方玩法参考链接。进度仅存于本次页面内存，不读取或写入浏览器存档。重置本次进度需要页面确认，仅影响此游戏。运行 `node check-scratch.cjs` 和 `node check-scratch-ui.cjs` 检查结算、不同刮区布局、固定票面、结算与本次页面交互；后者使用项目已有测试依赖实际渲染票卡，不代替真实浏览器的布局检查。

最新增加合成大西瓜：物理碰撞、连续合成、警戒线、暂停和本次最高分；小游戏已包含谷歌小恐龙。新增二维 CAD 编辑、分贝测试和 PDF 工具箱，综合计算增加 2–36 进制转换，编码与加密增加国际摩斯密码。

CAD 支持线段、圆、矩形、多段线绘制，对象移动和属性修改，撤销/重做、网格捕捉。现支持 DWG 导入、在线二维编辑、DWG 2000（AC1015）保存，以及 ASCII DXF/JSON 导入和 DXF/JSON/SVG 导出。圆弧可通过 DWG/DXF 导入并编辑；文字、图块、锁定图层实体、带弧段多段线及三维实体只读显示或保留。保存 DWG 时保留原图层、图块定义、纸空间及其他可写图纸数据；含不能完整写出的实体会停止导出。DWG 2000 使用索引色，自定义 RGB 颜色可能近似；标准三维视觉样式会由 CAD 软件重新创建。外部参照、专有代理对象及某些复杂图纸可能无法完整显示或保存。

DWG/DXF 最大 20 MB，模型空间最大 5 万实体，其中最多 2000 个基础二维实体参与交互编辑；其余只读保留。完整 JSON 工程保存原图数据与编辑记录，重新导入可继续编辑；撤销可恢复整张导入图纸。DWG 使用 nasjidwg 0.18.0（MIT）本地模块，源码及许可证在 `dist/vendor/nasjidwg`，SHA-512 与官方 npm 包核对。解析和写入放在后台 worker，超过 40 秒停止处理。DWG 功能需要 HTTPS/localhost。

运行 `node check-cad-dwg.cjs` 后再运行 `node check-plus-ui.cjs` 验证 DWG 处理与页面交互；测试依赖安装命令为 `npm install --prefix .test-deps --no-save jsdom @napi-rs/canvas @mlightcad/libredwg-web`。独立 LibreDWG 仅用于测试，不进入发布包。验证包含新增/删除/坐标修改、中文文字、图层、图块、纸空间、未改动记录、JSON 工程恢复，以及后台消息与跨图纸撤销。外部 AutoCAD 2018 样本来自公开 LibreDWG 测试库，仅保存在本地测试目录。

分贝测试由访客主动授权麦克风，默认显示数字电平加 100 dB 的未校准估算，可切换到原始 RMS 数字电平 dBFS，或填写参考分贝仪读数校准为估算声压级，支持平均值、峰值、趋势及 CSV 导出。麦克风未经校准，不能作为专业环境噪声仪；不提供 A/C 计权。离开工具或隐藏页面会关闭麦克风，不录音、不上传。

PDF 支持多文件排序合并、按页码提取和重排、逐页拆分 ZIP、旋转、页面预览及 PNG 导出、全文 TXT 提取、图片转 PDF。处理文件均留在当前浏览器；不提供 OCR 或加密 PDF 解密。浏览器预览需使用 HTTPS/localhost，不能依赖双击 file:// 页面加载模块。

格式转换新增 BMP 导出及 GIF/BMP/AVIF 图片读取，AVIF 编解码取决于浏览器支持；动图转静态格式只保留一帧。数据转换支持 JSON/YAML/CSV/TSV/XML：CSV/TSV 以二维数组读取，XML 用节点对象保留属性和文本。摩斯密码支持英文字母、数字和常用标点，中文需先转为拼音。

本次新增库使用本地文件：Matter.js 0.20.0、PDF-LIB 1.17.1、PDF.js 6.4.299 兼容构建、js-yaml 5.4.3 和 fflate 0.8.3。许可证与来源位于 `dist/vendor/plus-libraries.txt` 及对应 LICENSE 文件。

新增功能检查：`node check-plus.cjs`、`node check-cad-dwg.cjs`、`node check-plus-ui.cjs`、`node check-pdf-render.cjs`。后三项需要上述测试依赖。页面交互检查采用模拟 DOM 与真实后台处理模块，不代替真实浏览器的视觉验收；PDF 渲染检查会实际生成图像。测试依赖和生成文件不进入静态发布包。

无框架、无构建依赖的静态网站。打开 `dist/index.html` 即可使用，也可将 `dist` 目录上传到任意静态网站服务。

GitHub Pages 发布步骤见 [GITHUB_PAGES.md](GITHUB_PAGES.md)。已提供从 `dist` 发布的 Actions 工作流、静态资源检查与 ZIP 打包脚本，支持仓库子路径。

使用用户提供的二次元背景图，界面为冰蓝与米白色毛玻璃风格，没有紫色渐变或 emoji。图标是自带 SVG，不依赖外部图标服务。

包含逐字入场、分段淡入、菜单错峰展开、背景轻微视差、卡片悬停光晕、微光粒子、多级菜单、明暗氛围切换、移动端导航、QQ 复制和 GitHub 外链。支持键盘导航与减少动态效果的系统设置，页面隐藏时暂停粒子动画。

页面包括首页、与我联系、游戏大厅和工具目录。目录页只显示跳转入口，二级菜单链接进入各游戏或工具。联系页面包含 QQ、GitHub、B 站和 X。顶部菜单每个选项依次入场，路由切换不再自动展开下拉菜单。主页左上标题为“星月晓梦的个人站”，移除了“你好，我是”。

小游戏：贪吃蛇、2048（滑动与合并动画）、井字棋、五子棋（人机和双人）、扫雷（安全首步、标记模式及固定格子尺寸）、数独（随机唯一解）、俄罗斯方块（320 ms 消除动画、旋转、硬降与影子预览）、Flappy Bird（透明小鸟贴图，随速度平滑上扬或下坠）。提供键盘和手机操作；离开运行中的贪吃蛇、俄罗斯方块、Flappy Bird 时自动暂停。俄罗斯方块消除期间也可暂停和重开，减少动态效果时直接完成消行。

工具：综合计算（计算器、单位换算、BMI、等额本息/等额本金贷款、手动汇率）、HEX/RGB/HSL 颜色转换、PNG/JPEG/WebP 图片格式转换、JSON 格式化/压缩、图片裁剪/旋转/镜像/尺寸调整、二维码生成与 PNG 下载。

新增编码与加密：UTF-8 Base64 编解码、URL 编解码、SHA-256 摘要、AES-256-GCM 口令加密/解密。AES 使用随机 16 字节盐、随机 12 字节 IV，以及 PBKDF2-SHA256 210000 次派生。加密结果为包含参数的 JSON，可直接用于解密；口令不存储。SHA-256/AES 需要 HTTPS 或 localhost 的 Web Crypto。

实时天气：默认北京，可点击预设或搜索其他城市。通过 Open-Meteo 公共 API 获取最新模型天气、湿度、风速、体感和三天预报；显示数据时间及来源。当前天气页每 10 分钟刷新，离开时取消未完成请求；不请求地理定位。需联网，失败时提示重试，上次数据会明确标记。

二维码识别：本机读取 PNG/JPEG/WebP 图片，或点击后请求摄像头授权。扫码成功、离开二维码页、隐藏页面、关闭页面时关闭摄像头；识别出的内容不会自动访问，只有完整 HTTP/HTTPS URL 会提供手动打开按钮。

鼠标动效：淡蓝拖尾与点击扩散圆环，不阻挡页面操作，页面隐藏时停止；遵循减少动态效果设置。

汇率由访客手动输入，不联网获取行情。BMI 仅计算数值，贷款按固定利率测算，不含手续费。图片仅在当前浏览器处理，不上传；输入文件限制 20 MB 和 4000 万像素，图片编辑的导出尺寸最大为 4096 × 4096。JPEG 导出透明区域填白，WebP 导出需浏览器支持。

## 地图与心理测试

游戏、工具及心理测试使用一致的页内下拉菜单。选中状态按完整 hash 路径匹配，目录入口只在目录页高亮；导航链接仅跳转，由 hashchange 统一渲染，菜单不置于带入场动画的游戏面板内。目录卡片和页内菜单项沿用首页的鼠标浮动光效，遵循减少动态效果设置。

地图：`#tools/map`，使用本地打包 Leaflet 1.9.4（BSD-2-Clause，许可证在 `dist/vendor/leaflet/LICENSE.txt`），按需加载 OpenStreetMap 标准图块。支持城市快捷入口、Open-Meteo 城市名称搜索、地图点击选点、WGS84 经纬度跳转和复制。地图默认不响应鼠标滚轮，使用缩放按钮、双击或键盘；支持触屏缩放。搜索只在提交时请求，结果缓存于内存，离开页时取消。地图底图按浏览器标准 HTTP 缓存，保留 OSM 署名，没有批量下载或预取。自定义底图 URL 可通过 `SITE_CONFIG.mapTiles` 配置。

定位仅由访客点击触发；离开或隐藏页面后忽略未完成定位结果，不反向查询地址。地图及城市搜索需要网络，底图访问会将当前浏览区域的图块请求发送给 OpenStreetMap；定位跳转后也会请求该区域图块。定位功能没有自动触发或授权测试。

心理测试入口 `#psychology` 包含 PHQ-9、GAD-7、WHO-5、IPIP-50、IIP RIASEC 48 项职业兴趣、原创 MBTI 32 项、CES-D 20 项、CESD-R 20 项及 HAM-D 17 项。所有题面与选项为中文；结果直接显示分数。GAD-7 和 WHO-5 使用发布方中文版本，其余公开量表使用注明未经本地信效度验证的本站辅助译文。MBTI 为原创偏好探索，SCL-90 已移除。HAM-D 仅供合格专业人员记录访谈与观察，不作为自填测试。CESD-R 的 20 项版本不与早期 22 项中文版混用。计分依据及出处在问卷与结果页面显示。

答题内容只存于页面内存，刷新清空。PHQ-9、CESD-R、HAM-D 的自伤相关条目独立提供支持提示。来源及使用记录见 `references/README.md`；`node check-assessments.cjs` 验证分档、反向计分、症状组合和缺答校验。

新增本机创作工具：音频播放器显示波形，支持定位、拖选片段与 PCM16 WAV 裁剪导出；GIF 制作支持多图排序、单帧时长、循环与导出；流程图和思维导图支持节点拖动、连线、属性编辑（节点颜色与文字颜色独立设置，文字默认黑色）、撤销、JSON 项目保存和 SVG/PNG 导出；万年历支持 1900–2100 年的公历、农历与节日；像素画支持画笔、橡皮、填充、取色、撤销/重做、翻转、图片或 JSON 导入、透明 PNG 导出。刷新会清空未保存的作品，文件处理不上传。

GIF 编码使用 [gifenc 1.0.3](https://github.com/mattdesl/gifenc)，MIT 许可证保留在 `dist/vendor/gifenc-LICENSE.md`。音频最多 80 MB、15 分钟；GIF 最多 60 帧、640 × 640；像素画 16/32/64 格。`node check-studio.cjs` 验证 WAV 音频数据、GIF 编码、区域填充、图形项目校验及已知农历日期。

扫雷困难为 16 × 16 / 60 雷；数独困难保留约 24 个提示数，始终检查唯一解，难度仅按提示数划分。点击特效为半径最多 28 px 的单环与随机青金粒子，保留拖尾及减少动态效果支持。

`dist/selects.js` 将所有原生选择框统一为页面内 combobox/listbox 弹出菜单，保留原 select 值和 input/change 事件，兼容动态单位选项。支持方向键、Home/End、Enter、Escape、Tab 和前缀查找；下拉展开时暂停背景视差与粒子。固定位置菜单放在 body 层，避免处于毛玻璃和入场动画的合成层中。样式见 `dist/standard.css`。

珊瑚气泡（`#games/coral`）：将素材目录的 Java 游戏移植为原生 Canvas 游戏，人物、鱼类与海底场景全部重新绘制为本站原创 Canvas 图形，不加载素材目录中的图片。按实际源码保留同色气泡救援、最近的一人判定、每人 1 分、10 分解锁红色气泡、捕获后上浮与人物触及海床结束等核心玩法。经典模式一次失误结束；另有三次机会的轻松模式，两种模式均无时间限制。支持手机触碰、空格切色、方向键准星与回车救援，离页、失焦和页面隐藏时暂停；海域随分数变化，60 Hz 与 144 Hz 使用相同时间尺度，动画跟随浏览器刷新率。合成音效默认关闭。各模式最高分、分数里程碑、累计救援及音效选择仅在本次页面保留。运行 `python sync-coral.py` 同步本地预览，`node check-coral.cjs` 与 `node check-coral-ui.cjs` 检查规则、交互、页面内存、生命周期和实际 Canvas 渲染；测试不替代浏览器布局检查。
